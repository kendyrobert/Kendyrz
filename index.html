📎 Media a Enlace

Sube una foto, vídeo o música y obtén un enlace directo (.jpg, .mp4, .mp3…) para usarlo en otra web o app.

En Cloudinary: Settings → Upload → Add upload preset → Signing mode: Unsigned. Los datos se guardan solo en tu navegador.

Arrastra archivos aquí o toca para elegir Fotos, vídeos y audio
¿Cómo funciona y qué limitaciones tiene?

Una página HTML sola no puede guardar archivos en internet: necesita un servidor. Por eso esta web envía tu archivo a un servicio de alojamiento y te devuelve el enlace directo.

• tmpfiles.org: sin configuración, pero el enlace se borra a la hora. Ideal para pruebas.
• Cloudinary: enlaces permanentes y rápidos, con plan gratuito. Recomendado para uso real.
• Local: enlace blob: que solo existe mientras la pestaña esté abierta.
